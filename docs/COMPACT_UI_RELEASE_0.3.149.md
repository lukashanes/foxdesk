# FoxDesk 0.3.149 — kompaktní rozhraní

Kompaktní, ploché rozhraní požadavků, času, reportů, klientů a nastavení.
Aktivní záložku označuje výraznější text, ne barevná kapsle nebo podtržení.
Menší mezery, neutrální ovládací prvky a čitelné světlé i tmavé zobrazení.
Mobilní cíle zůstávají minimálně40px, zachované je ovládání klávesnicí a RTL.

Ověřeno na naplněné izolované instalaci:44 obrazovek, pět interakčních kontrol,
24 jazyků, generované CSS, PHP syntaxe a hranice self-hosted aktualizací.
Mobilní seznam odděluje odkaz na ticket od odkazů na štítky; odstraněny jsou
dekorativní barevné okraje řádků. Funkce a oprávnění se nemění.

Vydání neobsahuje nové databázové migrace ani změny konfigurace.
Před aktualizací zazálohujte databázi, config.php a zákaznická úložiště.
Při návratu obnovte předchozí soubory0.3.148; konfiguraci a data nepřepisujte.
Balíček není automaticky nasazen do zákaznických self-hosted instalací.
